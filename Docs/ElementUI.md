# 四章像素 UI 规范

视觉基准：用户提供的 `四元素-像素UI.html`。游戏内 HUD 使用原网页 Canvas 导出的透明贴图，不使用近似图标、普通矢量图或平滑字体替换。封面是独立的已确认设计。

## 主题与布局

- Chapter01 → ice；Chapter02 → grass；Chapter03 → earth；Chapter04 → fire。游戏内不提供主题切换按钮。
- 像素倍率 K = clamp(floor(屏幕宽度 / 460 + 0.5), 2, 4)。文字牌使用 max(1, K − 1)，暂停弹窗使用 K。
- 地图键距屏幕左、上各 6K；右侧控件组距右、上各 6K。
- 图标按钮基准尺寸 19×21，地砖面 17×15；相邻按钮间隔 2K。右侧顺序：撤销、重置、红蓝连接块、声音、暂停。
- 提示牌贴在按钮下方；通知位于右侧、距顶 50K，持续 1.6 秒。
- 普通/悬浮/按压按钮分别使用网页的 1/0/3 像素抬升与 3/4/1 像素侧边厚度。

## 绘制与资源

- 资源：`Assets/BetweenPoles/Resources/ElementUI/`，命名 `{主题}-{功能}-{状态}`。
- 所有 UI 贴图 Point、Clamp、无 mipmap、无压缩、保持 NPOT 原尺寸、透明背景。只按整数倍放大。
- 字体使用网页 `ptext`：SimSun → NSimSun → Microsoft YaHei，小字号 Canvas 绘字，alpha > 100 硬阈值，阴影向下 1 像素。主要 UI 文案已经导出为贴图。
- 新增固定文案也应通过网页相同函数导出，不用抗锯齿动态字体冒充。调试工具的动态文本可使用宋体回退。
- 通用面板使用同一地砖底色、亮边、分带、侧边；由 `ElementGameUI.Panel` / `PixelGameUI` 绘制。
- 暂停蒙层为 2×2 棋盘格，一半透明、一半主题深色 alpha 0.9；弹窗居中，无额外黑框。
- 编辑/提取/验证工具放 `E:/CodexTool/ElementUI`，不要放项目 Assets 中。

## 交互

- Tab：打开/关闭实际小岛地图；保留游戏中已有缩放、拖拽、检视、航图过场。
- Z：实际撤销；R：实际重置当前小岛。键盘由 GridPlayground 处理，HUD 不重复执行。
- M：声音开关；恢复之前的音量。Esc/P：暂停；再次按下或点击暂停画面恢复。
- 地图模式左上进入星际航图、右上返回游戏；滚轮不自动进入航图。
- 进入地图不使用网页占位星域内容，不提供切换四元素按钮。未探索岛屿、传送限制等仍由游戏规则管理。
- 暂停、转场、开场动画和检视时必须阻止冲突输入；关闭/销毁暂停界面需恢复原 timeScale。

## 编辑状态预览

四章场景的 GridPlayground 对象已保存 ElementGameUI 组件，无需进入 Play 模式即可在 Game 视图查看 HUD。Scene 视图开启 Gizmos 且勾选组件的 Show In Scene View 时也会预览。Inspector 的 Editor Panel 可选择 HUD 或 Pause 查看暂停弹窗。编辑预览不执行游戏操作，也不创建声音组件；进入运行模式后恢复正常交互。


## UI 大小与末岛调试快捷键

游戏内 HUD、提示牌、暂停弹窗、地图导航按原尺寸统一放大 1.5 倍，编辑预览同步。贴图选择仍使用原网页倍率，显示倍率额外乘 1.5，避免提示牌资源丢失。

正常游玩时按主键盘 3 或小键盘 3，跳到本章编号最大的房间；旧关卡无编号时按数组末尾。优先使用末岛已有调试落点，否则选择该岛无石头、磁铁的地块。暂停、地图检视、开场、飞行和移动期间不触发。无独立调试 UI 按钮。
