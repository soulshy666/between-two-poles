# 头盔内低模人脑 V3

2026-10-05。依据用户新提供的人脑参考图：整体肉色、简化脑叶与弯曲沟回，不做彩色功能分区。保留已经回退到第一版的宇航服和腰侧密封盒。

## 实现

- 第一版头盔外壳仅移除正面遮挡的中央面，保留原切角外轮廓与完整顶盖。新增深色内衬与窗口边框，保留少量反光表现。不使用额外透明玻璃 Shader。
- 脑体为连续低模曲面，中间纵裂、两侧弯曲沟回由几何凹凸表现；下方加入简化小脑与短脑干。没有纹理、五官、彩色分区或深色描线。
- 脑体统一使用 brainFlesh 材质 #CCA59C。网格使用平滑法线，不依赖细分曲面。
- 脑体本身 1844 三角面，加托座 44 面；整个人物合计 5362 面。仍为身体与密封盒两个 Renderer，但含多个材质槽。
- 生成源：build-geometry.cjs；生成数据：unity-geometry.json；接入脚本：update-in-unity.cs.txt。
