# 两极之间 主角形象设计 V1

角色定位：一名自愿携带密封装置、向太阳出发的普通宇航员。气质安静、专注，有劳动与探索的实际感。头盔保护角色的匿名性，适应剧情用“你”称呼主角的第二人称叙述。性别、姓名、具体年龄均不新增为故事设定。

## 设计依据

依据资源目录中的《两极之间 剧情与分镜脚本 人物设定修订版》及《两极之间 两格桥修订版(1)》，并结合工程 PRODUCT.md 与现有角色。

- 剧情第 2 张和制作备注：身体完整的普通人。造型不使用义肢、脑舱、疾病暗示或超能力光环；耐受磁场的原因仍保持未知。
- 剧情第 5 张：有编号、检验封签、稳定指示灯的密封装置牢固固定在身侧。模型采用右腰稍靠后的位置，保留手部向前推动空间。侧挂是剧情要求，具体右侧为本版设计选择。
- 结局第 5、6 镜：盒子亮起、揭晓用途，最后人物仍抱着它。盒子保持独立部件，便于后续制作解扣、抱持及投影表现。本次模型不含这些动画或剧情功能。
- 策划第 1、6 节：斜俯视格子解谜、角色不能主动跳跃、红蓝磁铁要醒目。主角采用中性暖白，装置采用低饱和暗金，避免把角色误读成 N/S 极物件。背部仅表现生命维持模块，不设置喷射口。

## 造型

切角方形大头盔保留原项目的几何语言，以倒角减少积木拼接感。面罩为横向深蓝黑色玻璃，只有少量冷灰反光，无卡通眼睛。颈圈、肘部和膝部露出深色软连接，让身体结构一眼可读。

胸腹紧凑，肩部略宽，手套厚实，双脚留出明显间隙。胸前仪表与两侧固定带交代任务服的实用结构。背包贴身，避免遮住侧面的盒子。全身不加武器、披风、大天线或漂浮部件。

密封盒是第二识别点：硬质暗金外壳，深色防撞框，分离的运输锁扣与封签，顶部一个稳定小灯。预览中的深色短线仅代表示意编号位置；最终编号需作为贴花单独制作。前期不出现基因、幼苗、DNA 图案或“人类基因库”文字。

## 可交付内容与使用边界

astronaut-v1.obj 与 astronaut-v1.mtl 是同一预览造型的静态低模草案。单位按 Unity 一单位约一米，Y 向上，+Z 为正面，脚底为 Y=0，高度接近原角色。OBJ 分对象保留身体和装置部件，使用纯色材质，无外部贴图依赖。

这次提供角色造型设计与模型草案，尚未替换现有 Player.prefab 或任何章节实例。模型没有骨骼、蒙皮、碰撞或动画，也没有配置 Unity 弯曲世界 Shader。密集小部件便于审核造型，正式接入时宜按动画分组和材质合批，避免一零件一 draw call。

交互预览用正交投影检查四面轮廓；像素按钮为低分辨率示意，不是 Unity 的实际渲染截图。正式画面仍需在项目的灯光、55 度俯角、384 高渲染缓冲与轮廓后处理中复核。

## 后续接入约定

保留 Player 逻辑根与 Visual 外观节点。旧有四章实例已经覆盖每个身体部件的 Mesh 与材质，需有针对性地迁移外观覆盖，再统一引用新外观；不能单纯修改原预制体材质后假定全场景同步。保持各场景位置、朝向、地表锚点及 GridPlayground 引用。

模型接入后先验证走格、推动、反冲和磁流升降；表现动画再加入小幅肩臂发力、步态与护住盒子的动作。结尾取下盒子并抱持应作为单独动画安排。
