## 回滚方式

收到回滚要求后退出 Play，并检查相关文件是否有后续改动。

若当前内容仍与替换后哈希一致，可从上述备份恢复对应的两个文件，再让 Unity 重新导入。四章会随 Player.prefab 自动恢复。不要使用 git reset --hard 或回退整个项目。

若文件已被后续编辑，应选择性移除本次新增的 Visual/AstronautVisual 嵌套实例，并把原 Torso、Helmet、Visor、Left boot、Right boot、Left arm、Right arm、Sealed box 八个 MeshRenderer.enabled 恢复为 true。保留所有其他新增工作以及各场景根节点和玩法引用。

新增 AstronautV1 资源可保留以便重新试用；移除场景引用即可恢复旧角色，无需删除资源。外观变化只涉及上述目标，项目中同时存在的磁铁、桥和调试面板改动不属于本次替换。
