# 两极之间 Unity 场景原型

打开 `Assets/BetweenPoles/Scenes/FirstSignal.unity`。

## 编辑与观看

地块、磁铁、人物、岩石、背景、灯光和相机均已序列化在场景中。进入 Play 不会生成或加载关卡几何体。场景在停止 Play 后仍完整存在。

- Scene 窗口：选择、移动、复制场景对象；保持地块与磁铁中心在 1.5 单位的格点上。
- Game 窗口：即使不启动 Play，也能看到最终像素画面。Scene 编辑视图本身不加像素滤镜，便于选择对象。
- `05 CAMERAS / World Camera / Pixel World Camera`：调整内部渲染高度（默认 384）及轮廓强度。正交相机决定构图。
- 镜头以当前星球居中，正交尺寸 4.3，俯角约 55 度。`Island Camera` 的 `Island Centers` 指定星球中心；跨越空隙时保持原构图，到达另一座星球后平滑转移。移动中心锚点可直接调整各岛构图。
- `Assets/BetweenPoles/Prefabs`：地块、红蓝长条、红蓝 U 型、人物。
- 地块 `GridTile`：`Blocked` 是障碍格，`Goal` 是抵达格。
- `06 GRID RULES`：地块、磁铁采用显式引用数组，新增实例后需加入对应数组。场景中的位置信息决定逻辑格坐标。

## 试玩

点击 Play 后在 Game 窗口操作。WASD / 方向键每次按下走一格，R 重置；没有跳跃。方向沿世界格子轴，W 向画面上方。

从出生点向右走，推动红色长条进入蓝色长条所在格，二者沿短边并排吸附，形成一格宽落脚面。随后走到右侧信标所在格，灯变亮。空隙不可直接行走。

合成使用两块原磁铁实体，不添加遮住形状的桥面。原始磁铁占用格子，玩家站在后方独立格；成品允许玩家站到实体上。

## 本轮范围

本轮为画风与场景编辑流程验证关卡，不是完整网页版移植。包含按格行走、单块推动、平行异极长条合并、简单同极推移/反冲和重置。U 型提供可编辑模型与基础推移，尚未移植连续滚动、圆环合成、U 加两根长条的两格桥、升降磁流、十字与重量规则。

渲染使用 Unity 2022.3 内置管线：低分辨率 RenderTexture、Point 采样放大、深度/法线边缘后处理、硬边模型、低光泽材质、暖色主光与冷色环境光。没有安装 URP 或覆盖项目全局渲染配置。运行期只分配渲染缓冲，不构建场景。

场景创建和验证脚本保存在 `E:/CodexTool/unity-scene-reference`。原来的 SampleScene 保留。
