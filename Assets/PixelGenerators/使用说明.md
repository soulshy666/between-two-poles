# 像素生成器：Unity 中文移植

## 打开场景

- 太空背景：`Assets/PixelGenerators/Scenes/PixelSpaceLab.unity`
- 星球：`Assets/PixelPlanetLab/Scenes/PixelPlanetLab.unity`（已升级原实验室）

选中“中文太空背景生成器”或“中文星球生成器”，Inspector 可以调参数和使用 Unity 原生颜色选择器。Game 窗口有“生成、颜色、图层、导出”四个中文分页，编辑状态和播放状态均可预览动画。播放状态调整后请使用“保存全部设置与颜色”，以免退出播放时被 Unity 恢复。

## 星球工具

移植原版 12 种天体：湿润类地、干燥类地、海岛星球、无大气岩星、气态巨星、星环巨星、冰雪世界、熔岩世界、小行星、黑洞、旋涡星系、恒星。每一种使用对应的原始着色器和分层参数，不是同一模型换色。

支持种子输入与随机地形、像素精度、倾角、光照（滑块和预览区拖动）、像素抖动、独立图层开关、逐色 RGBA 和十六进制编辑、随机配色、恢复原色、颜色文本复制/粘贴/导入。

PNG 为透明背景；GIF 和动画图集按原版自定义周期采样。可调整帧数、时长、图集列数和间距。天体本身的动画方式沿用各自算法，并非全部都只是球体自转。

## 太空背景工具

移植星尘、星云、星点图集与球面背景行星。支持尺寸、随机种子、配色、透明输出、分层开关、像素模式、减弱背景、平铺和边缘留空。

新增星云/星尘缓慢移动与扭曲、星星错峰闪烁、行星漂浮。每项可独立调节，也可暂停全部动画。种子决定 0–4 颗行星及其位置和尺寸；平铺预留了边缘接续对象。所有预览对象预先保存在场景中。

背景动画按指定时长采样导出 GIF 或图集；空间平铺不等于时间上的无缝循环。平铺时噪声频率按周期对齐，构图会与非平铺模式有所变化。

## 导出与保存

文件位于 Unity 项目根目录 `PixelGeneratorExports/像素星球` 或 `PixelGeneratorExports/太空背景`。每次使用唯一文件名，不覆盖之前的输出。

动画逐帧导出，有进度和取消按钮；取消后 `.partial` 文件仅为未完成输出。GIF 使用每帧最多 256 色的调色板，为免依赖外部程序使用简单编码，因此文件可能比专业 GIF 压缩工具生成的更大。

设置 JSON 保存全部天体颜色、图层与主要生成参数；“载入已保存方案”可恢复。颜色文本要求颜色数量与当前天体一致，输入错误时不会部分覆盖颜色。

## 直接用于 Unity 的导出（新增）

两个实验室的“导出”分页及 Inspector 均提供：

- **导出 Unity 预制体**：保存到 `Assets/PixelGenerators/Exports/`，导出后自动选中资源。保存当前配色、图层、种子和动画参数，不包含实验室面板或预览相机。
- **导出 Unity 资源包**：同时创建预制体，并保存 `.unitypackage` 到项目根目录 `PixelGeneratorExports/UnityPackages/`。适用于其他采用 Built-in 渲染管线的 Unity 项目；通过 Assets → Import Package → Custom Package 导入。

同一项目的背景使用步骤：在太空实验室调好效果 → 导出预制体 → 打开 FirstSignal 游玩场景 → 在 Project 中选中刚导出的背景预制体 → 菜单“两极之间 / 生成器 / 将选中的背景预制体应用到当前场景” → 保存场景。菜单自动停用旧背景并绑定游戏相机，不删除旧对象。

背景也可以直接拖入 Hierarchy；已有背景时请先停用旧背景，必要时在“目标游戏相机”中指定实际渲染世界的相机（本游戏是 World Camera）。背景自动跟随镜头、等比例铺满视野，比例不同时裁剪画面边缘，不调整游戏镜头。星球预制体为透明的动画天体，可直接拖入场景并调整位置和大小，默认朝向相机；它是视觉资源，不包含可行走地块或碰撞。

动画使用实时着色器，颜色和速度仍可在实例的 Inspector 中修改。编辑状态已存在全部对象，播放时无需重新生成地形。导出时若暂停动画，预制体也保留暂停状态；恢复播放请取消“暂停”。运行游戏期间也可导出，从而保留当时调整的结果。

太空实验室新增“陨石对撞”开关、间隔、大小以及“立即预演陨石对撞”。效果包含双陨石接近、扭曲多色火焰、爆炸冲击波与碎片；这些内容随预制体一同导出。位置可在 Inspector 的“碰撞位置”调整。所有导出使用新的目录，不覆盖先前方案。
